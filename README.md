<h1>Human movement track app</h1>
<p>The following program performs the task of visual human motion capture.
<br>
</p>

<p>
The basic capabilities of the application include:
- displaying three windows: calibration settings, calibration preview, and live preview,
- saving the operator-set parameters to a file,
- restarting the positions of the detection areas,
- capturing the movement of markers after correct calibration of parameters,
- tracking the movement of markers,
- reading the positions of tracked markers in real-time
in pixel units,
- saving to a file the read values of the joint angle as a function of time
with an accuracy of two decimal places.
</p>
