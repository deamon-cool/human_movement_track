<h1>Human movement track app</h1>
<p>The following program performs the task of visual human motion capture.
<br>
</p>

<p>
The basic capabilities of the application include:
</p>
<ul>
  <li>displaying three windows: calibration settings, calibration preview, and live preview,</li>
  <li>saving the operator-set parameters to a file</li>
  <li>restarting the positions of the detection areas</li>
  <li>capturing the movement of markers after correct calibration of parameters</li>
  <li>tracking the movement of markers</li>
  <li>reading the positions of tracked markers in real-time in pixel units</li>
  <li>saving to a file the read values of the joint angle as a function of time with an accuracy of two decimal places</li>
</ul>
